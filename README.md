## ✨ What Is SiriGlass?

SiriGlass is a visual effects package for SwiftUI, the modern way to build Apple-style apps. It recreates the exact liquid-glass animation Apple introduced with the Siri drop: a soft, translucent orb that slides out of the Dynamic Island at the top of the screen, wobbles like real liquid, and then lights up when it hears you speak.

Instead of hand-building layers of blur, reflection, refraction, and voice-reactive glow, you attach a single modifier — `.siriGlass($state)` — and the whole effect appears. That means you can add a premium, futuristic look to your app in seconds instead of weeks.

In short: it is the easiest way to make an app feel like it shipped with iOS 27.

## 🎤 How It Works

SiriGlass is built around a single, friendly idea: a drop of glass that reacts to sound.

**The drop.** A rounded, liquid-looking shape emerges from the Island area at the top of the screen. It is not a flat image — it is live geometry that bends and stretches as it moves.

**The liquid.** The surface of the drop shifts like real water. Light reflects off the curved edges, the center stays clear, and the shape settles into a gentle wobble when it stops moving.

**The glow.** When your microphone picks up sound, the glass lights up from the inside. Quiet speech produces a soft shimmer; a loud voice produces a bright, pulsing bloom. It calms down again when you stop talking.

**The modifier.** Behind all of this is one line of code — `.siriGlass($state)` — which reads the current state of the effect and applies every layer, animation, and light response at once.

You get the result of a complicated effect without touching any of the complications.

## 🧩 Features

- **Voice-reactive lighting.** The glass brightens, dims, and pulses in response to microphone input in real time.
- **True liquid motion.** The drop stretches, compresses, and settles with physically believable movement rather than a simple fade.
- **Dynamic Island origin.** The animation starts exactly where the Island sits, so it feels native to the system rather than layered on top.
- **One-line integration.** A single modifier attaches the entire effect. No setup chains, no configuration files.
- **Live state binding.** Because the modifier reads a state value, the effect can be paused, reset, or replayed on demand.
- **Smooth performance.** The heavy visual work is handled by the graphics hardware, keeping the animation fluid even on modest machines.
- **Ready-made presets.** Several brightness and intensity levels are included so you can match different moods without fine-tuning anything.
- **No account required.** Nothing to sign up for, no license key to enter, no email address to hand over.
